# Fair People Analytics Ranking (Synthetic Demo)

**A reproducible teaching prototype for ranking-quality and fairness audits. It is not a hiring product.**

This project compares two simple models over an entirely synthetic dataset:

1. A model trained to reproduce simulated historical decisions. The simulated decisions deliberately contain group and proxy effects.
2. A reference model trained on a synthetic job-signal label generated from skills and a work-sample score.

Protected attributes are used only for post-hoc auditing; they are not model inputs. The example also demonstrates why simply omitting protected columns does **not** guarantee fair outcomes: correlated proxy features and biased historical labels can still affect rankings.

## Important limitations and safe use

- All records and outcomes are generated by code. There are no real candidates, employers, job descriptions, or hiring decisions.
- Do not upload real candidate data or use this prototype to screen, rank, shortlist, or make decisions about people.
- The labels and group effects are invented for instruction. They are not empirical findings and should not be interpreted as evidence about any real group.
- A group-level metric is a diagnostic, not a legal conclusion or proof of fairness. Metric choice, target validity, sample size, intersectional effects, accessibility, and local law all need careful human review.
- The reference model is a teaching comparator, **not a demonstrated bias-mitigation method**. A model can have balanced group metrics and still be invalid or harmful.
- The demo is offline only. It has no applicant interface, persistent candidate database, real-data ingestion, deployment, or automated decision workflow.

## What it measures

- `precision_at_k`, `recall_at_k`, and `NDCG@k` against the synthetic `qualified` label.
- Selection rate and qualified-candidate recall at `k`, reported separately by synthetic gender and age groups.
- A visible warning when a group has fewer than 30 records in the test split; the group is still reported, not silently dropped.
- Reproducibility from a fixed random seed.

The metrics are computed on a held-out test split. Group rates are shown with group counts; do not interpret rates without considering their denominators and uncertainty. Groups below 30 records are flagged because their estimates can be unstable. This initial version reports marginal groups separately and does not perform intersectional analysis or confidence intervals.

## Run on Windows

From this repository folder in PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[dev]"
$env:PYTHONPATH = "src"
python -m pytest
python -m people_analytics
```

Run a larger or different reproducible experiment:

```powershell
python -m people_analytics --n 5000 --seed 17 --selection-fraction 0.2
```

The command writes four files under `reports/`: `experiment_summary.json`, `historical_decision_model_fairness_audit.csv`, `job_signal_reference_fairness_audit.csv`, and `synthetic_test_scores.csv`. The generated report files are ignored by Git so that outputs can be reviewed locally before deciding what to publish.

## Method

The synthetic generator creates skills, a work-sample score, education-access and experience proxy features, and audit-only group attributes. A synthetic qualification probability depends on the job-signal features. Simulated historical decisions depend on qualification plus intentionally introduced group/proxy effects.

The training split fits the historical-decision model on all four non-protected features and fits the reference model on the two job-signal features. The held-out split is ranked by each score, and top-`k` results are compared. Neither model uses gender or age as an input.

## Example run

With `python -m people_analytics --n 1000 --seed 42`, the held-out set contains 300 synthetic records and the audit uses `k=60`. The historical-decision model and job-signal reference produced NDCG@60 values of approximately `0.887` and `0.889` in that run. The example demonstrates that similar aggregate ranking quality does not establish fair treatment: group selection and recall rates differ, and the nonbinary test group is small and flagged. These are simulated outputs, not real-world evidence or claims about any group.
